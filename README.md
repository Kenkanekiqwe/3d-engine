# CryHorror Engine

A custom C++20/OpenGL 3D engine and horror-game prototype.


## Realistic asset sources

The environment is being rebuilt around CC0 Poly Haven vegetation (Pine Tree 01, Fir Tree 01 and Pine Sapling Medium) rather than stylized low-poly packs. Poly Haven assets are CC0. The planned house is the photogrammetry Forest House Ruin by matousekfoto (CC BY 4.0); keep attribution with the game.

Powered by Poly Haven assets.
